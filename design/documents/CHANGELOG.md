# 更新日志（维刻 Vex）

## v0.3.0（2026-10-18）

- [新增] 统一维刻 Vex 品牌、墨青 Logo、各平台应用身份和安装包；提供 Windows、macOS、Linux 和 Android 公开下载。
- [新增] 六种导图结构、章节原位编辑、表格及 Markdown 元素菜单、原生数学 / 化学公式与 Mermaid 图表。
- [新增] 文档和导出水印独立设置；桌面本机 MCP 服务、客户端配置及安全确认。
- [优化] 默认关闭自动保存，恢复草稿独立控制；保护输入法候选、保存期间的新增输入及重复关闭操作。
- [优化] 打开文件自动加载所在目录及子目录中的 Markdown 树，跨目录切换时恢复对应目录。
- [优化] 大文档后台解析、结构索引缓存和按需布局；修复章节跳转位移与滚动时文字延迟绘制。
- [优化] 自适应布局、真实光标居中的打字机模式、专注模式、独立只读内置文档和偏好设置。
- [新增] SSH 一键触发 GitHub 多平台构建，校验七个安装包及 SHA-256 后公开 Release；本机 Windows 打包入口保持独立。

0.x 仍是早期版本，跨平台真机、输入法、复杂排版和完整原型一致性尚需继续验收；iOS / HarmonyOS 可安装包暂缓，不提供占位 IPA / HAP。

## 设计原型阶段记录（2026-10-17）

- 😄[新增] 文档水印，可设置文字与不透明度，正文显隐和导出包含分别控制，默认关闭。
- 🔨[优化] 新手引导贴近目标，使用小三角气泡，缩短提示与操作之间的距离。
- 🔨[优化] 品牌统一为「维刻 Vex」，沿用 V 图形和墨青配色，slogan 为「写下想法，看见脉络」。
- 🔨[优化] 七类菜单和七类偏好设置；自动保存默认关闭，恢复草稿独立设置。
- 🔨[优化] 代码块预留语言栏，聚焦与失焦保持布局稳定；Mermaid 支持展开源码与预览。
- 🔨[优化] macOS 遵循系统习惯；手机单视图，平板最多双栏；鸿蒙覆盖手机、平板和电脑原型。
- 🔨[优化] 鸣谢与更新日志使用随应用安装的 Markdown，不复制到用户目录；桌面独立只读窗口，手机和平板保留对话框。
- 😄[新增] MCP 本机服务设置、客户端配置、连接测试与审计的交互原型。

## v0.2.2（2026-10-17）

- 🐛[修复] GitHub Release 更新时的集成令牌权限错误。
- 🔨[优化] 从 v0.2.2 源码重新构建安装包，发布前核对标签与源码提交，上传后验证 SHA-256。
- 🔨[优化] 同名附件内容不一致时拒绝覆盖。
- 🔨[优化] Windows 长文档源码视图的可见行布局与 Skia 渲染后端。

## v0.2.1（2026-10-17）

- 🔨[优化] Windows 源码视图按可见行布局，改善长文档滚动与内存占用。
- 😄[新增] 正文与导图演示、自定义标题栏、统一文档历史和四种界面语言。
- 🐛[修复] Android SDK 初始化、Linux ARM64 工具链引导及 macOS 通用架构校验。
- 😄[新增] 自动测试、原生构建、安装包制作与完整性检查流程。
- 🔨[优化] Android 使用固定发行证书与正式包名，每个安装包附 SHA-256 校验文件。

---

v0.2.1 与 v0.2.2 为历史开发预发布，日期以 [GitHub Releases](https://github.com/dotnet9/Vex-Flutter/releases) 为准，当时仅提供 Windows、macOS、Linux 和 Android 安装包，没有可安装的 IPA / HAP。

“设计原型阶段记录”保留当时的设计范围，不将鸿蒙原型当作已交付平台。各版本的实际安装包和校验文件以对应 GitHub Release 为准。
