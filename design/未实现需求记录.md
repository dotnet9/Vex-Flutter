# 原型确认后补实现的需求

以下交互已先在桌面原型中补齐，待原型验收后再进入 Flutter 实现：

1. **正文内容区宽度**：阅读与即时编辑视图参考 Typora，取消居中栏宽限制（原 1280/780px），正文随内容区铺满、仅保留约 48px 内边距；演示模式排版不变。原型已改（`editing.css`、`workbench.css`），待 Flutter 同步。
2. **侧栏分隔条拖动反馈**：拖动左侧栏与中间文档区之间的分隔条时，分隔条和侧栏边界应跟随鼠标实时移动，拖动结束后记住宽度。
3. **文件节点右键菜单**：文件树、文件列表中的文件和文件夹节点支持右键菜单，提供“在新窗口打开”与“打开文件位置”；文件节点把当前内容带入新进程，文件夹节点在新进程进入打开文件夹流程；“打开文件位置”在应用内调用系统文件管理器并定位到该节点。
4. **旧版 Windows 窗体上边框**：Windows Server 等旧版 Windows 上补齐窗体标题栏上方边框，高版本 Windows 保持当前效果。

## Markdown 能力的原型验收入口

桌面原型样例 `assets/desktop/samples.js` 新增《Markdown 功能示例.md》，用于确认以下界面表达：

- 嵌套无序列表：缩进两个空格后显示子列表，编辑和阅读保持层级。
- `[TOC]`：显示可点击的目录项，点击后滚动并高亮对应标题。
- 表格：未写 `:` 对齐标记时，表头与列默认左对齐。
- 脚注：正文引用、文末内容和返回正文箭头均可点击。
- Callout：`INFO` 使用信息色，`WARNING` 使用警告色，均以窄边框提示块呈现。

这些内容已同步到 `docs/新手引导演示剧本.md` 的“Markdown 功能演示与界面约定”，不并入新手引导主线。
