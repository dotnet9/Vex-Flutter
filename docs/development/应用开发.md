# 应用开发

最终应用位于 `apps/vex`，入口为 `lib/main.dart`。开发环境和运行步骤见 [开发调试与测试入门](../06-开发调试与测试入门.md)，分层及目录说明见 [仓库地图](../01-仓库地图与目录说明.md)。

应用版本由安装包元数据读取，第三方声明通过 Flutter LicenseRegistry 显示。更新依赖或应用版本后，在仓库根目录执行 `python scripts/sync_project_info.py`，同步原型版本信息及主要组件的原始许可声明。生成脚本要求先执行 `flutter pub get`，不需额外 Python 包。

内置更新日志和鸣谢只维护在 `docs`，手动启动或测试应用前执行 `python scripts/sync_builtin_documents.py`。完整打包和 CI 自动生成离线资源，安装后的程序不读取仓库或向个人文档目录复制正文。
