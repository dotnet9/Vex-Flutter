# 脚本导航

脚本随源码维护，不依赖旧电脑上的工具目录。先按用途找入口，不需要逐个运行所有脚本。

| 用途 | 目录 / 脚本 | 什么时候使用 |
| --- | --- | --- |
| **构建安装包** | 根目录 `publish_win-x64.bat`；[完整说明](打包与发布.md) | Windows 双击制作 x64 安装包；其他平台在对应系统使用 `scripts/packaging` 中的现有入口 |
| **远程全平台发布** | 根目录 `publish-release.bat` / `packaging/publish.py` | 经确认后 SSH 推送新标签，由 GitHub Actions 构建并公开 Release；不是本机跨平台编译 |
| **一键清理** | 根目录 `clear.bat` | 删除可再生的 `build`、`.dart_tool`、`ephemeral` 与 `artifacts`；先退出正在运行的 Vex |
| Windows 插件目录绕过 | `packaging/win-x64/Fix-PluginDirs.ps1` | Win11 24H2+ 非管理员构建或运行前修复 `.plugin_symlinks`；`-Restore` 还原清单 |
| 安装器源码与静态资源 | `installer/` | 修改安装界面、安装行为、许可或背景资源 |
| 脚本自动测试 | `tests/` | `python -m unittest discover -s scripts/tests -v` |
| Windows 安装卸载验收 | `test_windows_installer.ps1`、`test_windows_shutdown.ps1` | 单独执行，遵循安装测试的隔离要求，不是日常打包入口 |
| 品牌资源 | `sync_brand_assets.py`、`render_brand.py` | 修改根目录 Logo 后同步 / 渲染品牌资源 |
| 安装器资源生成 | `prepare_installer_assets.py`、`prepare_macos_installer.py` | 修改安装器图片后重新生成；正常打包无需重复生成 |
| 字体准备 | `prepare_app_fonts.py`、`prepare_export_fonts.py` | 更新应用 / 离线导出字体 |
| 原型与应用同步 | `sync_design_tokens.py`、`sync_builtin_documents.py`、`sync_project_info.py` | 更新设计令牌；从 `docs` 生成内置文档；同步项目版本元信息 |
| 演示模式维护 | `test_presentation.cjs`、`update_presentation_l10n.py` | 验证原型演示、维护演示文本翻译 |
| README 实机媒体 | [采集说明](首页媒体采集.md) | 采集 Windows 应用截图、六步新手引导 GIF |
| 验收辅助 | `compare_workspace.py`、`summarize_stress.py` | 比较源码副本、汇总压力测试结果 |

`artifacts/`、各项目的 `build/`、`.dart_tool/` 是生成目录，不是脚本源码；不提交到 Git，也不必随换机迁移。签名材料不属于可丢弃缓存，需单独加密备份。
