# 鸣谢

维刻 Vex · 写下想法，看见脉络。

感谢每一位提出建议、报告问题、参与翻译和贡献代码的朋友。

## 开源社区

| 项目 | 在 Vex 中的用途 |
| --- | --- |
| Flutter / Dart | 应用框架与语言 |
| Markdown 与编辑组件 | 文档解析、编辑与阅读 |
| Mermaid | 流程图与时序图 |
| KaTeX / mhchem | 原型中的数学与化学表达式 |
| Cascadia Code | 代码字体 |
| Noto Sans SC | 离线 PDF 的中文字体 |

完整依赖与许可证见 [开源组件许可](../design/Third-Party-Licenses.html)。各项目与字体遵循各自的许可证。
