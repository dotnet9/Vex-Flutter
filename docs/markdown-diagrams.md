# Mermaid 图表实现与验证

## 实现范围

- 使用 `mermaid_core` / `mermaid_flutter` 0.3.0 原生 Dart 引擎，不依赖 WebView、JavaScript 或在线服务。
- 菜单按过程与行为、计划与演进、结构与关系、数据与比较分组，覆盖原型中的 22 类模板。
- 帮助菜单可新建完整图表示例文档，不替换当前未保存内容。
- 即时编辑中点击或按 Enter / Space 展开源码，预览持续保留在下方。
- 输入防抖 240 ms，中文组词期间不提交中间状态；Esc、Ctrl/Cmd+Enter 或点击外部收起并保留修改。
- 语法错误保留源码与上一次正确图形；修改与普通正文共享撤销历史，保留文档换行格式。
- HTML 内嵌 SVG、PDF 绘制矢量图并嵌入中文字体、Word 内嵌 PNG。导出不需要联网。
- 不执行图表链接与脚本；渲染前限制源码为 64 KiB、1000 行，并限制输出尺寸。

## 已验证

- 原型 22 个模板分别通过解析、布局与 SVG 测试。
- 22 类模板在 Flutter 阅读视图、HTML、PDF、Word 中生成实际图形。
- Windows 原生窗口按 1280 x 900、390 x 844 尺寸，分别检查浅色、深色与源码展开状态。
- 覆盖中文输入、错误预览保留、快捷键收起、撤销、CRLF 与空白工作区插入。
- 视觉检查产物位于忽略目录 `artifacts/review/mermaid-2026-10-18/`。

## 兼容边界

引擎支持的图表类型不等同于 Mermaid.js 每一项语法细节均已完整兼容。未覆盖的新语法会显示错误并保留源码，不能以模板测试通过宣称与所有 Mermaid.js 扩展完全一致。其余 6 类引擎扩展类型仍可通过源码输入，但尚未加入产品模板菜单。

本项验证也不代表整个应用已达到原型 98% 的目标；完整验收仍需覆盖公式、上下文菜单、设备适配与安装流程。
