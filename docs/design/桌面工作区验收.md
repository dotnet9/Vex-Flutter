# 桌面工作区对照验收

2026-10-20，Windows，简体中文，1440 × 900 逻辑像素，缩放 100%，品牌墨青浅色，正文采用“简约”。原型使用无界面 Chromium，应用使用 Flutter 离屏渲染；两者均加载本机字体，不操作桌面鼠标或键盘。

## 已完成的对齐

- 左侧只保留文件导航，右侧独立显示文档结构；大纲可过滤、拖动调宽、用方向键调宽、关闭，并记忆设置。窄窗口临时收起，恢复宽度后恢复用户偏好。
- 七个主菜单按用途组织子菜单，保留命令和快捷键。长菜单在 800 × 480 窗口和大字号下检查边界，支持键盘进入子菜单。
- 窗口、正文、菜单、弹窗、导图和滚动条使用同一配色；九种正文排版以完整文章预览。
- 格式工具栏跟随编辑视图，底部提供文件导航、源码和右侧大纲开关；三视图采用上方源码与阅读、下方导图的结构。
- 查找与替换保留当前布局，定位全部可见视图；长段落重复命中进入可视区。滚动联动不移动光标，不增加撤销记录，同章节内保留导图手动平移。
- 对齐 Windows 简体中文字体、源码默认字号与留白、导图节点宽度与间距、折叠控件、图例和操作提示；新打开导图定位当前章节，没有章节定位时定位文档根节点。

## 实测边界与配色

坐标为 `[左，上，宽，高]`，不通过空白像素面积计算相似度。

| 区域 | 原型 | Flutter | 最大误差 |
| --- | --- | --- | --- |
| 文件导航 | 1, 100, 226, 799 | 0, 99, 226, 801 | 2 px |
| 正文工作区 | 232, 100, 963, 799 | 231, 99, 964, 801 | 2 px |
| 文档结构 | 1199, 100, 240, 799 | 1200, 99, 240, 801 | 2 px |

正文纸张色均为 `#FFFEFB`，文件导航、右侧大纲和工作栏均为 `#F3F6F2`。这些采样与主框架边界可以复测，但不是整产品“98% 一致度”的量化结论。

## 验证边界

锁定依赖下：核心包 24 项、编辑器 232 项、导图 22 项、应用 343 项、脚本 78 项测试通过；静态分析、全部 255 个 Dart 文件格式检查、原型契约和 Windows 调试版编译通过。

离屏截图不能替代各系统实机验收。Chromium 与 Flutter 的字形栅格化、段落与表格细节、原生复选框以及导图内容节点高度仍有差异；文件树遵循应用自身的排序设置。完整产品尚未完成逐页面的 98% 一致度评定。

本机不运行 Android、macOS、Linux 的实际安装与输入法验收；跨平台构建、Android 原生回归和安装包验证由版本标签触发的 GitHub Actions 执行。唯一沿用的应用跳过项是需要显式配置官方 MCP Inspector CLI 的外部检查。
