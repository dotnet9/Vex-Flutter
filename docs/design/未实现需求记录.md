# 原型确认后补实现的需求

以下交互已先在桌面原型中补齐，应用同步状态逐项记录（2026-10-20）：

1. **正文内容区宽度** ✅（v0.6.0 调整）：即时编辑充分使用内容区；阅读按所选排版限制行宽，源码、表格与多视图按可用空间展示。演示与导出仍按各自排版处理，应用端见 `packages/vex_editor/lib/src/editor.dart` 与 `workspace_panes.dart`。
2. **侧栏分隔条拖动反馈** ✅：拖动实时跟随鼠标，拖动结束记住宽度（持久化 `sidebarWidth`）；并补齐悬停/拖动高亮与聚焦后左右方向键 ±10px 微调。
3. **文件节点右键菜单** ✅：文件树与文件列表中的文件和文件夹节点均支持“在新窗口打开”与“打开文件位置”；文件把当前内容带入新进程，文件夹在新进程进入打开文件夹流程（启动参数支持文件夹路径）；“打开文件位置”调用系统文件管理器并定位。
4. **旧版 Windows 窗体上边框** ✅：应用自绘标题栏常显顶部 1px 边框作为旧系统回退线，高版本 Windows 效果保持。Windows Server 目视确认仍建议在目标系统安装包上复核。
5. **文件树“全部折叠”** ✅（原型与应用已同步）：v0.6.0 将折叠与树形 / 列表切换归入文件栏底部“更多”，折叠只影响展示。
6. **空行间距规则** ✅（原型与应用已同步）：标题底部基础间距收紧到 Typora 量级；阅读视图按块间空行数渲染——第一个空行不产生额外间距，每多一个空行补一行正文高度，保留作者的疏密意图。
7. **自动保存时静默重载外部修改** ✅（应用行为）：已开启自动保存且文档无未保存改动时，外部修改自动重载并提示状态；有未保存改动或未开启自动保存时仍弹“重新载入/另存当前内容”横幅。原型无文件监听，不涉及。
8. **检查更新移至帮助菜单**（原型已改，待应用同步）：关于对话框只保留版本徽章，去掉“更新日志”与“检查更新”；帮助菜单新增“检查更新”，按参考设计实现五态流程——检查中（旋转指示）→ 发现新版本（英雄区含版本号、发布日期与一句摘要，主按钮“下载更新”，更新内容默认折叠）→ 下载中（进度条、已下载/总量与剩余时间，可取消）→ 下载完成（自动展开更新内容，稍后安装/立即安装）→ 已安装。多版本时按倒序列出之间所有版本，条目带 新增/优化/修复 类型标签；版本与日志解析自内置《更新日志》文档。

9. **布局调整：左侧文件与右侧辅助面板** ✅（v0.6.0 原型与应用已同步）：左侧常驻文件窗格；右侧共用大纲、文章信息与章节编辑，默认收起，宽窗口可调宽，小窗口覆盖显示。底栏和视图菜单均可打开大纲，点击章节定位正文与导图。

10. **保存反馈、偏好自动保存与 MCP 单开关启停** ✅（原型与应用已同步）：文件保存失败可重试或保存副本；偏好有效改动自动持久化，与正文自动保存开关分别控制。MCP 开关直接启停，运行状态紧贴开关显示；外观提供浅色、深色、跟随系统三个单选项。验证范围见 [桌面工作区验收](桌面工作区验收.md)。

## Markdown 能力的原型验收入口

桌面原型样例 `assets/desktop/samples.js` 的《Markdown 功能示例.md》已同步为应用内置文档（帮助菜单 → Markdown 功能示例，或 `docs/Markdown功能示例.md`）：

- 嵌套无序列表：缩进两个空格后显示子列表，编辑和阅读保持层级。
- `[TOC]`：显示可点击的目录项（带“目录”标题与描边），点击后滚动并短暂高亮对应标题。
- 表格：未写 `:` 对齐标记时，表头与列默认左对齐。
- 脚注：正文引用、文末内容和返回正文箭头均可点击，定位后短暂高亮。
- Callout：`INFO` 使用信息色，`WARNING` 使用琥珀警告色，均以窄边框提示块呈现；标签行支持同行文字并从正文剥离。
