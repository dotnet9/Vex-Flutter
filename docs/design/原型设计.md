# 维刻 Vex 设计原型

维刻 Vex · 写下想法，看见脉络。

仓库的 `design` 目录包含用于评审的 HTML、CSS、JavaScript 和品牌素材，本文件只维护说明。除明确写出仓库根路径外，下文的原型资源路径均相对于 `design`。Flutter 应用实现在 `apps/vex`；原型的版本与第三方许可由实际项目数据生成。安装流程页面仍为设计原型。

## 打开

在仓库根目录运行 `node design/scripts/preview.cjs` 后访问 `http://127.0.0.1:4317/design/index.html`。需要 Node.js 和 Python，预览服务会从 `docs` 自动生成内置文档；未安装第三方 Node / Python 包也可预览，无需访问外部字体或 CDN。

也可先执行 `python scripts/sync_builtin_documents.py`，再用现代浏览器直接打开 `design/index.html`。直接打开 HTML 时，改动文档后需重新执行生成命令；预览服务则在请求文档资源时自动更新。生成物被 Git 忽略，离线评审保留生成后的整个 `design` 目录及下述共享代码字体。

- `index.html`：桌面、手机、平板及六个平台安装流程的导航。
- `Vex.html`：桌面工作区，沿用 Vex 原型的布局和主要交互；手机、平板参数自动转到自适应原型。
- `Vex-Adaptive.html`：手机单页、平板分栏的触控布局。
- `Appearance.html`：八套配色和九套排版，使用同一篇文章连续比较。
- `Vex-Installer-*.html`：Windows、macOS、Linux、HarmonyOS、Android、iOS 的安装或获取流程。

## 桌面菜单

保留文件、编辑、段落、格式、视图、工具、帮助七个主菜单及已有功能。常用操作直接展示，较长的同类命令归入子菜单：

- 文件：新建、打开、保存；导出按格式归组，文档属性、文件位置、编码和删除归入“文档操作”。
- 编辑：撤销、重做、剪贴板、查找替换和自动配对输入。
- 段落：正文、标题、列表、引用及块元素；表格按行、列、对齐归组，Mermaid 按用途分类。
- 格式：行内文字样式、链接、图片和清除格式。
- 视图：文档视图、编辑方式、侧栏与大纲、编辑显示、写作模式、外观和窗口。
- 工具与帮助：偏好设置、统计、刷新、发布平台、MCP，以及引导、更新和产品信息。

标题菜单和桌面右键菜单使用单层面板；子菜单按需展开，在窗体边缘自动避让。每一级完整展示操作，不使用滚动菜单；较矮窗口采用紧凑间距。支持方向键、Home / End、逐级 Escape、点击外部关闭和 Alt + 菜单助记键。

顶部中央使用唯一的视图选择入口，包含即时编辑、源码编辑、阅读、思维导图、源码＋预览、源码＋导图、即时编辑＋导图和三视图八种组合。选择后菜单自动收起；支持方向键、Home / End、Enter 与 Escape，关闭后焦点返回视图按钮。文件名与保存状态位于左侧，查找与保存副本位于右侧。

底栏左侧只保留文件导航与大纲入口，右侧显示字数及选区统计；多视图时增加联动状态、自由浏览与回到编辑位置。点击字数打开文章信息，不再弹出单独的统计窗口。编辑工具集中在编辑栏，阅读保留排版入口并限制行宽；源码、表格和多视图充分使用可用空间。

大纲、文章信息、章节详情共用右侧辅助面板，默认收起。宽窗口可以调整面板宽度；剩余正文空间不足或三视图较拥挤时改为覆盖面板，点击正文、文件栏或按 Escape 关闭，不压缩正文。查看导图章节正文也使用此面板，保留章节标题和正文编辑、升降级、移动、删除、定位与撤销。关闭面板保留所选章节；切换文档后不展示上一份文档的章节内容。

文件栏使用浅色背景、宽松行距与清晰选中态；底部保留新建、文件夹和更多，折叠与列表切换收进更多。工作区减少边框、阴影与大面积强调色，保留墨青色和统一圆角。新手引导通过帮助菜单主动打开。

以上改版已同步到 Flutter。桌面辅助面板默认宽 312、可调整至 280–480 逻辑像素；正文剩余宽度小于 640，或三视图工作区不足 1400 时覆盖显示。章节标题和正文即时同步到文章，文件是否自动写盘仍由文件偏好决定。手机保留适合单栏的导航与统计对话框。

`design/scripts/browser-workspace-chrome.cjs` 使用已有 Playwright 离屏验证八种组合、辅助面板、键盘焦点、实时统计、章节编辑和撤销，以及 800×480、1024×768、1440×900 的明暗布局；截图位于 `.dart_tool/prototype-workspace-chrome/`。Flutter 对应回归位于 `apps/vex/test/workspace_chrome_test.dart`，设置 `VEX_CHROME_CAPTURE_DIR` 可输出截图；四种语言和外观单选回归位于 `localization_test.dart`。

## 桌面主题与多视图

顶部外观弹出层将明暗模式直接展示为浅色、深色、跟随系统三个单选项，取消循环切换按钮和说明文字。选择后立即生效并保存设置，面板保持打开以继续比较配色；跟随系统会响应系统明暗变化。八套配色与偏好设置保留，原型和 Flutter 使用同样的交互。

窗口、正文、菜单、弹窗、工具栏、排版预览、导图和滚动条共享当前配色的语义变量。正文不再固定使用独立的黑白背景和蓝色链接。正文排版保留九种样式，左侧选择，右侧用完整文章展示标题、段落、引用、列表、表格和代码；紧凑布局同步作用于预览和正文。

编辑与阅读按正文块之间的相对位置实时双向同步；大纲跟随当前章节，导图只在章节变化时定位，保留同一章节内的手动平移。隐藏视图不参与滚动计算，新打开的视图继承当前正文位置。导图节点和大纲点击也会定位其他已打开的视图。

主题切换只更新属性和颜色变量，不重建正文、排版文章或导图。Mermaid 在首次渲染时将界面主题色转换为 CSS 变量，后续配色和明暗切换保留原 SVG。

原型已检查：800×480 至 1440×900 的菜单边界、长“视图”菜单连续开合、九种排版与紧凑布局、长文双向滚动、八套配色的浅色与深色。连续换色时，正文位置及流程图、时序图的 SVG 标识保持不变。Flutter 已同步工作区和外观交互；SVG 保留检查仅适用于浏览器原型，正式应用使用原生渲染，尚未完成帧率基准或所有 Mermaid 图种的逐项视觉验收。

## Markdown 演示

桌面从视图菜单进入“演示模式”，或按 F5；自适应原型的视图菜单及手机更多菜单也提供入口。标题生成独立页面，`---` 可显式分页；支持大纲直达、前后翻页、Home / End、字号调整与 Esc 退出。长页面可滚动，退出保留原工作区布局和编辑位置。演示不会修改源文。

演示栏提供“正文 / 导图”切换，两者共用当前页和大纲。导图翻页会聚焦对应节点；可平移、缩放或查看全图，点击节点定位章节，双击节点回到正文。演示中不提供节点重排或正文修改。

大图总览在低于 20% 且超过 300 个节点时省略无法辨认的节点文字；放大或聚焦章节恢复完整节点。原生实现此时直接绘制卡片，避免同时创建上千个文字与拖动控件。

程序使用相同的分页规则与四语言控制文案。桌面原生演示进入全屏，退出恢复进入前的窗口状态。浏览器支持时请求全屏，不支持时仍可在窗口内演示。`assets/presentation.js` 与 `assets/presentation.css` 为桌面、自适应原型共用实现。

## 品牌与外观

品牌主色统一称为“品牌墨青”，浅色主色值 `#24766B`。默认外观为纸白背景＋品牌墨青；深色模式使用更明亮的对应强调色。用户选择其他界面配色时，Logo 保持品牌色。

原型统一引用 `assets/vex-logo.svg`：沿用 V 形轮廓，使用品牌墨青底、白色 V。安装流程、导航和关于页面共用此素材。原生图标和安装包使用仓库品牌资源，实际打包入口见 [打包与发布](../development/打包与发布.md)。

八套界面配色：品牌墨青、石墨、海蓝、沙金、蔷薇、鸢尾、橄榄、陶朱。每套均覆盖浅色与深色的背景、文字、边框、按钮及选中状态。旧方案中相近的蓝、青、紫色已合并，用中性灰、玫红和橄榄色补足差异。

当前提供九套结构不同的阅读样式：

| 名称 | 用途 | 主要区别 |
| --- | --- | --- |
| 简约 | 日常写作 | 清爽留白，正文色标题 |
| 文档 | 知识整理 | 分节细线，清晰层级 |
| 书卷 | 散文与长读 | 衬线字形、舒展行距、较窄行宽 |
| 技术 | 开发笔记 | 信息块标题，代码边框，较宽正文 |
| 专栏 | 观点文章 | 强标题、侧边标记、独立引用 |
| 刊物 | 发布阅读 | 窄栏、居中节标题、阅读节奏 |
| 学术 | 论文与报告 | 衬线字形、居中主标题、双线分隔 |
| 手札 | 随笔与日记 | 轻量衬线标题、虚线分节、柔和引用 |
| 手册 | 操作与参考 | 色块节标题、清晰层级、紧凑信息块 |

紧凑间距是独立开关，不再作为一套排版重复计数。正文排版与界面配色独立设置，Markdown 内容不因外观切换改变。桌面、手机和平板共享配色及排版定义；HTML 导出带入所选排版。

## 工作区和交互

桌面保留 Vex 的文件与大纲、即时编辑与源码、阅读、导图、章节编排、导出、演示和引导。主工作区为单窗口；鸣谢和更新日志是独立文档窗口，不属于拆分工作区。

八种视图组合：即时编辑、源码、阅读、导图、源码＋预览、源码＋导图、即时编辑＋导图、三视图。三视图上方为源码和正文预览，下方为整宽导图。所有视图共用当前文档。

八项用户体验调整已同步到 Flutter 正式应用。浏览器评审入口为 [本轮原型验证](../../design/Usability-Review.html)，提供以下八项调整及独立场景：

1. 布局入口显示当前组合和用途，单视图切换与底栏辅助面板开关分开表达，多视图标记当前操作栏。
2. 文件名下持续显示未保存、只读、下载失败或副本下载发起状态；点击查看来源、浏览器下载位置、最近下载时间及草稿状态。失败可重试，失败后不清空修改。原型无法确认浏览器最终落盘，下载发起不等于保存完成。
3. 明确区分文件名查找、当前正文查找和当前标题筛选；文件名无结果时提供清除筛选与正文查找入口，查找与替换保持当前布局。
4. 默认收起大纲，将明暗和八套配色收进外观面板；引导改为主动打开。小窗口进入三视图时收起文件导航，底栏可手动恢复；低窗口增加导图高度并减少画布留白，保留结构概览，可放大或切换单独导图阅读。
5. 多视图提供联动开关、当前跟随来源及回到编辑位置；自由浏览不拖动其他栏，返回时保留用户选择的联动状态。
6. 导图默认只显示标题，选中后查看正文；拖动显示落点、目标层级和携带范围。章节修改后可直接撤销，后续正文已有修改时避免撤销错误的操作。
7. 底栏为文件、源码／即时编辑、大纲提供文字、下一步动作说明和开关状态；固定底栏为正文留出空间，文件栏新建入口增加文字。
8. 增加空工作区、未命名、无标题、长文、长文件名／深目录、草稿恢复和下载失败场景；字数明确中文按字、英文按词，不计 Markdown 标记和空白，选区单独计数。排版预览可切换当前文章与完整示例文章。

离屏浏览器交互检查：先启动预览服务，再使用已有 Playwright 环境运行 `node design/scripts/browser-usability.cjs`。脚本验证保存失败与重试、查找范围、自由浏览返回、章节移动及撤销、排版预览、空白写作和 800×480 至 1440×900 布局，截图输出到被 Git 忽略的 `.dart_tool/prototype-usability/`。该检查不替代真实用户试用或 Flutter 应用验收。

Flutter 对应实现使用真实文件保存与恢复草稿状态，文件名下区分保存中、待保存、保存失败、已保存时间和恢复后待保存；详情可重试或另存。导图默认只显示标题，显式保存的旧偏好继续生效。正式应用回归位于 `apps/vex/test/workspace_usability_test.dart`，可设置 `VEX_VISUAL_OUTPUT` 输出离屏截图。

可评审即时编辑、源码联动、Markdown 格式插入、查找替换、撤销重做、文件切换、导图平移缩放与折叠、章节改名和正文编辑、新增与移动章节、升降级、删除、原文恢复和引导演练。Markdown / HTML 可下载为副本；高级导出与部分工具仅展示页面状态。浏览器不会自动写回导入的原文件。

导图首批提供单侧树形、双侧平衡、中心放射、向下树形、目录树和鱼骨图，不包含时间轴。桌面、手机和平板共用 D3 hierarchy 布局；切换保留选中与折叠状态，不改变 Markdown 内容或章节顺序，鱼骨图不推断因果关系。演示导图沿用当前选定布局。

七类菜单为文件、编辑、段落、格式、视图、工具、帮助。macOS 使用左侧交通灯、Vex 应用菜单和 Cmd 快捷键。手机保持写作 / 阅读 / 导图单视图，平板最多双栏；HarmonyOS 覆盖手机、平板和电脑原型。

代码块始终预留 32 px 页脚空间，语言输入框仅在编辑时可见，聚焦与失焦不改变块高度。修改正文或语言同步回 Markdown 围栏；Esc 取消本次块编辑。源码行号独立设置。

Mermaid 图表点击后展开上方源码与下方预览，修改后延迟更新；块内交互保持展开，点击外部收起。无效源码保留，并显示错误和过期预览。菜单、对话框、设置详情与图表展开共用短时缓动，并尊重系统减少动态效果和界面动效开关。

## 偏好与内置文档

偏好设置覆盖通用与文件、编辑器、Markdown、图片、外观、导出和 MCP 七类，所有有效改动自动持久化，不需要点击应用；无效输入在字段附近提示并保留上次有效配置。文档自动保存默认关闭，与偏好设置自动保存无关。浏览器不写回原文件；启动行为、恢复、图片落盘和高级导出等原生能力仍以 Flutter 实现为准。

外观设置包含文档水印文字、不透明度、正文显示与导出包含，两个开关默认关闭且互不影响。视图菜单可快速显隐正文水印，源码、导图和内置只读文档不加水印；水印不写入 Markdown。HTML 副本会按导出开关包含水印，PDF 为带独立开关的结果预览，不生成实际 PDF。新手引导使用贴近目标的短三角气泡，桌面和平板、手机共用边界避让逻辑。

手机的更多操作与正文排版使用底部面板，不使用桌面级联菜单。常用文档操作集中排列，帮助与关于在面板内单层切换；支持遮罩、关闭按钮、Escape 和标题区域下滑收起，并保留焦点与减少动态效果偏好。写作、阅读、导图、大纲仍通过底部导航切换，平板保留紧凑浮层。

桌面 MCP 原型包含服务、客户端和审计页签，可演练端口与令牌校验、启停、HTTP 配置、stdio 桥接配置、连接测试、读取、修改确认及审计。全部是本地状态模拟，不启动真实服务。`mcpScenario=port-busy|unauthorized|timeout` 可演练错误。手机和平板不运行常驻服务；内置文档子窗口也不运行 MCP。

MCP 服务页只有一个启停开关：打开即启动，关闭即停止，移除独立的“应用”和“停止服务”按钮。运行状态紧贴开关下方，显示服务已停止、启动中、运行中及实际监听地址，失败时显示原因且开关回落关闭。底部仅显示设置保存状态。端口、令牌、授权目录等有效输入在停顿 400ms 后自动保存，开关与选项立即生效；关闭设置不会取消启动或丢失有效输入，无效字段也不会阻止停服。Flutter 使用真实本地服务与系统凭据存储；原型保留“原型演示”标记。运行 `node design/scripts/browser-mcp-autosave.cjs` 检查原型，`apps/vex/test/mcp_preferences_test.dart` 覆盖正式应用的启停、保存、令牌恢复及失败行为。

偏好设置桌面宽度为 675px，MCP 控件与其他表单一样靠右排列，输入框统一 180px；令牌显隐和重新生成按钮内嵌在输入框右端。关于对话框桌面宽度从 560px 收到 420px，自适应版从 480px 收到 360px，手机仍受屏幕可用宽度约束。

`docs/鸣谢.md` 和 `docs/更新日志.md` 是内置文档的唯一正文源。运行 `python scripts/sync_builtin_documents.py` 生成 `design/assets/generated/documents-data.js` 与 `apps/vex/assets/generated/documents/`，不手动编辑或提交生成物。文档随应用安装，不复制到用户目录。桌面原生使用新进程打开，浏览器使用独立窗口模拟；手机和平板继续使用可滚动对话框。

字体策略与原生应用一致：界面／中文使用各平台系统字体及回退链，书卷使用系统宋体；只随应用携带约 0.92 MiB 的 Cascadia Code，原型通过 `assets/fonts.css` 共享 `../apps/vex/assets/fonts/` 中的两份文件。离线评审应保留这部分目录；没有共享字体时仍可回退到系统等宽字体。应用不额外内嵌 Inter 或完整宋体字库。

## 评审参数

应用支持 `device=desktop|tablet|phone`、`platform=windows|macos|linux|harmonyos|android|ios`、`theme=light|dark|system`、`palette=weft|graphite|ocean|sand|rose|iris|olive|ember`、`typography=Simple|Basic|InkBlack|TechnologyBlue|Column|WeChatFormat`。

桌面布局：`layout=instant|source|read|map|source-render|source-map|instant-map|three`；兼容旧的 `source-read`。手机、平板使用 `source-read` 表示源码＋阅读。桌面 `scenario=empty|new|no-headings|long-document|long-files|save-error|draft|guide` 打开空工作区、未命名、无标题、长文、深目录、首次下载失败、草稿和引导场景。桌面语言使用 `lang=zh-CN|zh-Hant|en-US|ja-JP`，移动端 `lang=en` 仅切换主要导航。新增排版名称与部分交互文案尚未全部翻译。

`preview=1` 用于导航页内嵌预览，隔离浏览器持久偏好。普通应用页面只保存显示偏好，文档和撤销记录仍在内存中，刷新恢复示例；草稿恢复是预设场景。

安装流程支持 `theme=dark`、`scenario=installed|error`。异常场景首次失败，重试可完成。HarmonyOS 增加 `device=phone|tablet|desktop`；Android 增加 `update=1`；iOS 演练 GitHub Releases IPA、有效签名和设备授权，`scenario=unsigned` 展示不可安装状态。六个平台均具备可安装版本后统一通过 GitHub Releases 发布，本轮不发布真实包。

六平台自绘进度使用同一动画变量：百分比随进度移动并在两端避让，不显示复制路径、文件名或解包日志。`scenario=installing&progress=46` 可固定进度验收；实际点击安装仍会自动推进。macOS 保留拖入应用程序，Linux 保留软件包管理流程，iOS 保留签名与设备授权提示，不将 Windows 自定义安装选项套用到系统安装界面。

## 元素操作

桌面编辑区、源码和阅读区支持右键及 Shift+F10；分组箭头与标题栏菜单共用 Chevron 图标、尺寸和描边。级联菜单按视口翻转、限制高度，支持方向键、Escape 与点击外部关闭。手机和平板通过编辑区／阅读区标题右侧的更多按钮打开当前元素操作底部面板；文字长按仍交给系统选择菜单。面板固定标题和关闭按钮，只滚动操作列表。

表格在「段落 → 表格」和元素菜单提供行列插入、移动、删除、列对齐、复制、格式化源码及删除表格；表头与唯一列受保护，非表格位置禁用行列命令。不提供 Markdown 不支持的单元格合并。文字选区可剪切、复制 Markdown／HTML 代码／纯文本、粘贴、加粗、斜体、行内代码及删除；段落类型、标题级别、列表缩进和任务状态可转换。链接、图片提供地址复制、修改、取消链接或图片删除，图片支持预览与本地替换。代码块可编辑语言与正文，公式和 Mermaid 支持源码编辑、预览、复制、删除，Mermaid 保留原位展开源码与预览。

所有修改使用当前 Markdown 和现有撤销记录，不写回磁盘；阅读区和内置只读文档不提供修改操作。菜单捕获选区和元素位置，异步粘贴／文件选择前后验证文档是否变化，避免改错文档。剪贴板取决于浏览器授权，不可用时明确提示使用系统快捷键，不显示虚假的成功状态。复杂 Markdown 仍属于原型解析范围，正式编辑行为需在 Flutter 中另行实现和验证。

## 原型边界

所有安装、授权、替换、修复、移除、更新和商店获取都是状态演示，不修改系统。HarmonyOS 手机、平板和电脑页面是概念原型，正式系统界面与分发方式仍需结合设备和 SDK 验证。版本、包名、签名和获取状态不作为实际已发布信息。

浏览器原型用于评审视觉、布局和交互。应用使用 Flutter 原生渲染，单窗口、以本地文件为中心，代码位于 `apps/vex`；没有引入 SQLite、账户或云同步。复杂 Markdown、中文输入法、大文档与各平台文件访问、导出仍需持续工程验证，预览构建不代表各平台正式安装包已交付。
