# 统一打包脚本验收

## 修改范围

- 将原先散落在 `scripts/` 的构建、打包、签名准备和发布校验脚本归入 `scripts/packaging/`。
- 统一入口为 `scripts/packaging/build.py`，按 `win-x64`、`linux-x64`、`linux-arm64`、`osx-x64`、`osx-arm64`、`osx-universal`、`android` 提供平台快捷入口。
- macOS 架构入口仍共用一个双架构 DMG，发布产物命名和七包白名单不变；iOS 仅保留 `ios-check`，HarmonyOS 发布继续暂缓。
- 本机产物按平台和版本隔离到 `artifacts/local/`；CI 显式选择 `artifacts/release/`，使用同一套构建配方。
- 根目录 `build-windows.bat` 兼容旧双击习惯；对应脚本、CI、仓库文档与外部学习文档已同步引用。
- 显式抑制 Flutter 统计输出，避免首次启动提示污染 `--version --machine` 的 JSON；Android 校验工具固定使用 Build Tools 36.0.0。
- 历史 tag 重试需要选择相同 tag 自带的工作流，已增加路径预检与明确提示，不移动旧 tag。
