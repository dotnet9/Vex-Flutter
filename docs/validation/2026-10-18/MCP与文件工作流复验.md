# MCP 与文件工作流复验

本记录对应当前开发分支，不代表已发布 v0.3.1 安装包具备相同改进，也不宣布整个产品或全部平台验收完成。

## 已完成的逻辑

- 阅读/导图当前窗格不接收正文修改快捷键，双栏按实际活动窗格判断；格式工具栏与 Mermaid 插入也遵守这个边界。手机不再提供多栏布局按钮，操作面板按内容收缩。
- 文件树缓存展开后的行描述，使用按需列表创建可见控件。扫描默认忽略 `.git`、`.dart_tool`、`.idea`、`.gradle`、`build`、`node_modules`、`Pods`、`.symlinks`，允许在文件偏好中关闭；递归按目录推进，支持进度、取消和不可访问子目录跳过。
- Android 使用系统文档选择器和 content URI，iOS 增加文档提供程序与书签通道。可写来源保存原位置，只读导入提示保存副本；系统文档句柄不作为本地目录解析相对链接或图片。
- MCP 35 个工具补齐发现、查找、章节整理、导图布局和原子批量修改，强制校验参数模式；批量修改需要文档 ID 和 revision，拒绝重叠补丁和切开表情的偏移。
- 路径访问解析符号链接、限制文件类型及授权目录；异步授权、读取或打开期间切换文档会拒绝过期结果。令牌移入平台安全存储，存取及回读失败不开放服务。
- [MCP 指南](../../mcp/MCP使用指南.md)包括独立使用、接口参考、官方 Inspector 与复现方法；README、安全政策和设计文档同步更新。历史验收记录仍保留当时状态。

| `flutter analyze --no-pub` | 无问题 |

| Markdown 核心 | 24 通过 |
| 编辑器 | 223 通过 |
| 导图 | 16 通过 |
| 官方 Inspector 2.11.0 | 单独启用测试通过：初始化、strict schema、35 个工具全部调用并验证结果 |
| Windows 原生 MCP 集成 | 编译通过；独立测试凭据的保存/读取、令牌轮换/鉴权、关闭监听通过 |
| Android `compilePreviewDebugKotlin` | 通过；插件仍有 AGP/KGP 迁移警告 |
| 构建/品牌/发布脚本 | 55 通过 |

本机 JDK 的 Unix Domain Socket 回环连接异常曾阻止 Gradle 启动。本轮使用仅对命令生效的 `-Djdk.net.unixdomain.tmpdir=D:\vex-nonexistent-uds-path` 使 JDK 回退到 TCP 回环后完成编译，没有把机器相关目录写入构建脚本或修改系统网络配置。

首次从仓库根目录执行整个应用测试时缺少应用字体资源，改在 `apps/vex` 运行后资源测试通过；手机去掉布局按钮后，两个旧测试入口同步更新并重新跑完。不是忽略失败或删除测试。

## 仍未验收

- 官方 Inspector CLI 使用真实 Vex HTTP 与工作区逻辑，但数据/凭据为隔离替身；Windows 原生凭据另测，不等同于发行安装包的图形界面确认流程。macOS/Linux 安全存储、沙箱目录与目标 AI 客户端仍待实机。
- Android 此轮没有连接手机；系统文件提供程序跨重启授权、只读/云端来源、撤销授权后保存仍需真机。提供程序不支持原子替换时，不能承诺具备桌面本地文件同等的原子落盘保证。
- iOS 原生通道尚未在 macOS/Xcode 编译或真机验收，书签和导出授权需继续核验；iOS/HarmonyOS 发布仍按既定边界暂缓。
- 完整更新下载安装、校验、安装器就绪握手和关闭保护仍未完成；当前更新能力仍为版本检查与发布页入口，不能写成一键更新已交付。
- 非 Windows 源码长文档、复杂即时编辑几何和真实输入法/低配设备最差延迟，以及本轮变更后的原型完整对照仍需继续验证，测试数量不能证明 98% 还原。
