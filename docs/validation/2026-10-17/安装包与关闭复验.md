## 构建复现要点

在应用目录使用 `flutter build apk --release --flavor preview --target-platform android-arm64 --split-per-abi --no-pub`。明确按 ABI 拆包，避免通用包中保留插件的其他架构原生库。

本机 Windows 的 JDK 21 在系统临时路径下曾出现 `Invalid argument: connect`，导致 Gradle 无法建立回环连接。本轮仅为构建进程设置 `JAVA_TOOL_OPTIONS` 中的 `-Djdk.net.unixdomain.tmpdir` 和 `-Djava.io.tmpdir`，指向预先创建的短路径临时目录后构建成功；未修改系统全局配置。Android 生成的 `.kotlin/` 缓存已加入忽略规则。
