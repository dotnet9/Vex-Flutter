# 更新日志（维刻 Vex）

## V0.6.0（2026-10-20）

- 😄[新增]-桌面大纲、文章信息和章节编辑共用右侧辅助面板，支持调整宽度，小窗口覆盖显示；章节修改同步回文章并可统一撤销。
- 😄[新增]-多视图提供自由浏览与回到编辑位置，底栏展示正文及选区统计，顶部集中选择八种视图组合。
- 🔨[优化]-文件名旁显示保存状态，保存失败可重试或保存副本；查找范围和视图联动状态更明确。
- 🔨[优化]-偏好设置中的有效改动自动保存；MCP 通过一个开关直接启停，开关附近显示启动中、运行中、实际地址或失败原因。
- 🔨[优化]-外观浮层直接选择浅色、深色或跟随系统，九种正文排版提供完整文章预览。
- 🔨[优化]-文件导航与工具栏减少重复入口，新手引导改为主动打开；空白写作、章节整理和导图拖动预览更清晰。
- 🐛[修复]-修正编辑位置联动与纯文本字数统计，补齐章节编辑、四语言、小窗口和明暗布局回归。
- 😄[新增]-根目录提供 publish_win-x64.bat，复用已有工具链制作 Windows x64 安装包并生成校验文件。
- 🐛[修复]-本机打包自动补齐缺失插件链接，按需复用系统代理下载原生组件；可选浏览器检查与 CI 原型契约检查分别执行。

- 🐛[修复]-Linux 发布容器仅信任本次构建的 Flutter SDK Git 目录，修复缓存目录与容器用户归属不同导致的 dubious ownership 错误；x64 与 ARM64 在安装原生依赖前统一验证 SDK。（v0.5.2）

- 🐛[修复]-Linux x64/ARM64 发布容器改用 Ubuntu 20.04 自带的 Python 3.8，避免宿主缓存 Python 依赖更高版本 GLIBC 导致构建无法启动；统一构建入口兼容 Python 3.8，并在安装 Flutter 前执行预检。（v0.5.1；下列应用功能延续 v0.5.0）

- 😄[新增]-桌面右侧独立“文档结构”栏，支持标题过滤、章节跟随、调宽与显隐记忆，窄窗口临时收起后可恢复。
- 🔨[优化]-七个主菜单按用途整理子菜单，保留原有命令与快捷键，完善小窗口、大字号和键盘逐级操作。
- 🔨[优化]-八套配色统一覆盖正文、菜单、弹窗、导图和滚动条，九种正文排版提供完整文章预览。
- 🔨[优化]-编辑、阅读、导图与大纲实时联动定位；滚动不移动光标，同章节保留导图平移，新开视图接续当前正文位置。
- 🔨[优化]-查找和替换保持当前布局，在所有可见视图定位；复用重复查询结果，全部替换改为一次拼接。
- 🔨[优化]-对齐 Windows 简体中文字体、源码字号与留白、工具栏、底部导航及导图节点和折叠控件。
- 🐛[修复]-修复长段落中查找命中未进入可视区、导图切换分栏后偏出画面，以及源码重新挂载期间触发状态通知的问题。
- 🐛[修复]-修复发布流水线：Linux 安装包构建被 tzdata 时区交互提示卡死，构建依赖安装改为非交互模式；v0.4.6 应用内容与 v0.4.5 一致，补齐全部平台安装包。
- 🔨[优化]-解析热路径正则静态化、标题分节降为线性、目录锚点按修订缓存：长文档打字与滚动更跟手。（v0.4.5）
- 🔨[优化]-阅读视图样式表按配置缓存，未变更的块不再随输入重新解析；目录与脚注定位更快。（v0.4.5）
- 🔨[优化]-查找栏关闭后清空关键字，输入不再为残留关键字做全文扫描；状态栏词数改为防抖刷新。（v0.4.5）
- 🔨[优化]-外部文件变更轮询先比对修改时间与大小，未变化时跳过整文件重读。（v0.4.5）
- 🔨[优化]-导图去除冗余全树重排与重复通知：摘要与布局切换合并为一次重排，引导结束恢复更轻。（v0.4.5）
- 😄[新增]-首次进入应用自动弹出快速上手引导，看过一次不再打扰；工具栏“快速上手”改为常驻入口，随时重看。（v0.4.4-0.4.5）
- 😄[新增]-文件菜单新增快速打开（Ctrl+P）、文档属性（Alt+Enter）、打开文件位置、删除文档与选择编码重新打开（UTF-8/UTF-8 BOM/GB18030/Big5）；编辑菜单新增复制为纯文本（Ctrl+Shift+C）；视图菜单新增保持窗口在最前；工具菜单新增字数统计。（v0.4.4-0.4.5）
- 😄[新增]-文件树的文件夹节点支持右键菜单：新窗口进入打开文件夹流程、系统文件管理器定位目录。（v0.4.4-0.4.5）
- 😄[新增]-内置《Markdown 功能示例》文档：嵌套列表、[TOC]、表格对齐、脚注与 Callout 可从帮助菜单直接验收；目录与脚注定位后新增短暂高亮反馈。（v0.4.4-0.4.5）
- 🔨[优化]-新手引导对照原型补齐节拍：第二幕结尾句增量输入、第四/五幕展开面板在点击继续之后、第六幕先在源码逐字输入标题再切对照布局、第八幕拆分“保存入口”与“导出格式”两个停驻，第四幕收尾自动适应窗口。（v0.4.4-0.4.5）
- 🔨[优化]-即时编辑视图取消排版栏宽限制，正文随内容区铺满（参考 Typora）；演示排版与导出仍保留每主题栏宽。（v0.4.4-0.4.5）
- 🔨[优化]-侧栏分隔条悬停/拖动高亮，聚焦后支持左右方向键微调并记住宽度。（v0.4.4-0.4.5）
- 🐛[修复]-Callout 警告提示框改为琥珀色（浅色 #B54708/深色 #FBBF24），目录块补“目录”标题与描边，标签行支持同行文字。（v0.4.4-0.4.5）

- 🔨[优化]-Windows 界面字体栈调整为 Segoe UI 优先、微软雅黑回退，菜单栏与下拉菜单字重提升并加深颜色，观感更接近原生应用。
- 😄[新增]-根目录新增 clear.bat，双击即可清理构建缓存、测试缓存与本地产物。
- 🔨[优化]-开发与打包文档全面整理：移除开发期验收记录，补充 Win11 24H2+ 非管理员构建的插件目录绕过说明。
- 😄[新增]-发现新版后可在应用内下载安装包，支持进度显示、取消重试和完整性核验，Windows 会先保护未保存内容再交给安装器（v0.4.2）。
- 😄[新增]-恢复复制到微信公众号、知乎与稀土掘金的入口，文章可直接粘贴到对应发布平台（v0.4.2）。
- 🔨[优化]-新手引导直接展开排版、导图风格与菜单，提示更贴近操作位置，演练不改动原文（v0.4.2）。
- 🔨[优化]-正文提供九种排版，导图风格独立切换；导出与分享入口直接展示，减少多级菜单操作（v0.4.2）。
- 🔨[优化]-导图连线、节点和导出图片跟随所选风格，分支颜色保持一致，黑白风格与折叠按钮更清楚（v0.4.2）。
- 🔨[优化]-桌面鸣谢与更新日志在新的维刻进程中打开，以文件列表展示；手机继续使用固定标题和关闭按钮的阅读对话框（v0.4.2）。
- 🐛[修复]-修复 Android 启动时的异常提示，以及底部菜单被系统导航栏遮住、帮助无法点击的问题（v0.4.2）。
- 🐛[修复]-修复窗口在宽窄布局之间切换时菜单状态可能异常的问题（v0.4.2）。
- 🐛[修复]-调整排版、字号或窗口宽度时保留当前阅读段落，减少正文位置突然偏移（v0.4.2）。
- 🐛[修复]-修正 Linux 安装包的系统依赖基线和 macOS 打包权限，改善麒麟系统启动与 Mac 文件打开问题，仍需相应设备复验（v0.4.2）。

## V0.4.0（2026-10-18）

- 😄[新增]-统一维刻 Vex 品牌、墨青 Logo 和安装包，提供 Windows、macOS、Linux 和 Android 公开下载。
- 😄[新增]-提供六种导图结构、章节原位编辑、表格操作及 Markdown 元素菜单。
- 😄[新增]-支持数学与化学公式、Mermaid 图表，以及正文和导出独立设置水印。
- 😄[新增]-MCP 提供 35 个工具，支持文档查找、章节整理、导图布局和批量修改，并补齐连接与授权说明。
- 😄[新增]-文档可通过相对链接打开另一篇笔记并跳到指定章节，不会覆盖已打开文档的未保存内容。
- 😄[新增]-手机打开的可写文档支持保存回授权的原位置，只读来源明确提示保存副本。
- 🔨[优化]-写作区延伸到窗口底部，只保留侧边栏、源码切换和词数；文件页支持树形目录与摘要列表，大纲支持搜索。
- 🔨[优化]-打开文件自动加载所在目录及子目录，切换文档时恢复对应目录；大目录按需展示，默认跳过依赖与构建目录。
- 🔨[优化]-代码块支持多种语言高亮，可按语言名称或简称搜索，例如 C#、JS、Python。
- 🔨[优化]-导图滚轮平移，Ctrl + 滚轮平缓缩放；Enter 添加同级、Tab 添加子级、F2 改名，新增节点可立即输入标题。
- 🔨[优化]-界面主题色与正文排版独立设置，浅色正文采用白底，排版面板直接预览四级标题。
- 🔨[优化]-MCP 令牌使用系统安全存储，存储失败时不会回退为明文保存。
- 🔨[优化]-自动保存默认关闭，恢复草稿独立保护；鸣谢与更新日志保持只读，不占用个人文档目录。
- 🔨[优化]-手机操作面板更紧凑，常用文件操作更容易找到；窄窗口自动收纳顶部菜单并保留窗口操作按钮。
- 🔨[优化]-提高 Windows 安装界面文字和图标的清晰度，新安装默认放在 `%LOCALAPPDATA%\Programs\Vex`。
- 🔨[优化]-检查更新清楚区分已是最新、发现新版和本机版本较新，提供发布页入口，网络超时后可以重试。
- 🐛[修复]-修正源码行号对齐、斜体字形重叠和即时编辑方向键移动，切换文档时保留源码滚动位置。
- 🐛[修复]-减少点击代码块与列表时的页面跳动，改善大文档滚动和章节跳转时文字延迟出现的问题。
- 🐛[修复]-阅读视图不再误执行修改命令，修复排版浮层有时无法按 Esc 关闭的问题。
- 🐛[修复]-加强草稿恢复与关闭保护，设置读取异常不再跳过旧草稿，恢复记录损坏时尝试读取备份。
- 🐛[修复]-保护中文输入法候选、保存期间和关闭期间的新增输入，避免重复关闭操作丢失内容。
- 🐛[修复]-修正打字机模式的光标居中，改善内置文档的明暗阅读配色和 Windows 安装包构建。
