# 更新日志（维刻 Vex）

## v0.3.1 及后续改进（2026-10-18）

### 待发布改进

- MCP 新增查找、章节整理和批量修改等能力，连接与授权说明更完整；访问令牌使用系统安全存储，访问失败不会回退为明文保存。
- 阅读视图不再触发修改命令；手机操作面板更紧凑，常用文件操作更容易找到。
- 目录树按需创建可见内容，默认跳过依赖与构建目录；手机打开的可写文档支持保存回原位置，只读来源明确提示保存副本。
- 写作区延伸到窗口底部，只保留简洁的侧边栏、源码切换和词数；文件列表可切换目录树与摘要列表，大纲可独立搜索。
- 修正源码行号对齐、斜体字形重叠和即时编辑方向键移动；减少点击代码块、列表时的页面跳动，切换文档时保留源码滚动位置。
- 代码块支持多种语言高亮，可按语言名称或简称搜索，例如 C#、JS、Python。
- 导图滚轮默认平移，Ctrl + 滚轮缓慢缩放；Enter 添加同级、Tab 添加子级、F2 改名，新增节点可立即输入标题。
- 界面主题色与正文排版分开设置，浅色正文使用白底，深色模式照顾正文阅读；排版面板直接预览四级标题。
- 提高 Windows 安装界面的文字对比度和操作图标清晰度，新安装默认放在 `%LOCALAPPDATA%\Programs\Vex` 目录。
- 加强草稿恢复与关闭保护：设置读取异常不再跳过旧草稿，恢复记录损坏时尝试读取备份；关闭时继续输入会保留窗口和新内容。
- 文档之间可以直接通过相对链接打开并跳到指定章节；已打开文档的未保存修改不会被覆盖，文件不可访问时会提示。
- 窄窗口自动收纳顶部菜单，保留窗口操作按钮；修复排版浮层有时无法按 Esc 关闭的问题，改善内置文档的明暗阅读配色。
- 检查更新准确区分已是最新、有新版本和本机版本较新，并提供对应发布页入口；网络等待超时后可以重试。

### 本日已发布

- [新增] 统一维刻 Vex 品牌、墨青 Logo、各平台应用身份和安装包；提供 Windows、macOS、Linux 和 Android 公开下载。
- [新增] 六种导图结构、章节原位编辑、表格及 Markdown 元素菜单、原生数学 / 化学公式与 Mermaid 图表。
- [新增] 文档和导出水印独立设置；桌面本机 MCP 服务、客户端配置及安全确认。
- [优化] 默认关闭自动保存，恢复草稿独立控制；保护输入法候选、保存期间的新增输入及重复关闭操作。
- [优化] 打开文件自动加载所在目录及子目录中的 Markdown 树，跨目录切换时恢复对应目录。
- [优化] 大文档后台解析、结构索引缓存和按需布局；修复章节跳转位移与滚动时文字延迟绘制。
- [优化] 自适应布局、真实光标居中的打字机模式、专注模式、独立只读内置文档和偏好设置。
- [优化] 修复 Windows 安装包构建问题，提供可下载安装的 v0.3.1；每份安装包均附完整性校验文件。

本节合并同日的 v0.3.0、v0.3.1 记录。上面的“待发布改进”尚未进入已下载的 v0.3.1 安装包。

0.x 仍是早期版本，跨平台真机、输入法和复杂排版需继续验收；iOS / HarmonyOS 安装包暂缓。

## v0.2.2（2026-10-17）

- 改善 Windows 长文档源码视图的滚动和内存占用。
- 提供正文与导图演示、自定义标题栏、统一撤销记录和四种界面语言。
- 完善 Windows、macOS、Linux 和 Android 安装包的构建与下载校验。
- 设计原型补充文档水印、紧邻目标的新手引导、手机单视图和平板双栏，以及 MCP 设置等交互。
- 鸣谢与更新日志随应用安装，不复制到个人文档目录；桌面使用独立只读窗口，手机和平板使用对话框。
